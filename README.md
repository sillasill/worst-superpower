Worst Superpower — a make.fun bounty entry. A tiny deterministic Python program that writes one line inventing the most useless superpower to `entry.txt`: a hero who can speak fluent Pigeon, but only about parking, and only to pigeons who aren't listening.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
